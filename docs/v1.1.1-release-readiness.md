# RefAs 1.1.1 release readiness

RefAs 1.1.1 promotes the post-1.1 hardening line from `rc/post-1.1` to stable `main`. It is release-ready only when the exact candidate passes pull-request CI on Node 20, 22, and 24, and the exact merged `main` commit passes post-merge CI before the release workflow creates `v1.1.1`.

Every gate in [`release-criteria.md`](release-criteria.md) still applies. This document lists what 1.1.1 adds.

## Release identity

- `package.json`, `REFAS_VERSION`, and the Claude/Codex plugin manifests are `1.1.1`.
- New project state and whole-object certificates identify runtime `1.1.1`.
- Public v1 project-state and certificate schemas continue accepting `1.0.0` through `1.1.0` artifacts; `.../v1` namespaces are not renamed.

## Promotion boundary

`main` was held at the 1.0.4 stable line (#192) while 1.1.x hardening continued on `rc/post-1.1`. Promotion is an explicit pull request: the promotion merge records `main` history as a parent, and the resulting `main` tree equals the verified release candidate exactly. No force-push, history rewrite, or tag movement is involved; `v1.0.4` and `v1.1.0` stay immutable.

## Spatial volume closure

- A frozen spatial role is established before candidate evaluation and cannot be mutated by a later checkpoint.
- Planar/billboard collapse of a volumetric scope blocks downstream checkpoints through the whole-before-parts barrier.
- The protected spatial gate derives from trusted runtime authority; caller-authored `status: pass` and forged authority fields are ignored.
- Final certification requires exact final-candidate spatial continuity along the selected parent lineage. Stale or sibling-lineage evidence cannot satisfy it.
- Genuinely volumetric and intentionally thin candidates remain admissible.

Evidence: `npm run dogfood:volume-regression`, `npm run dogfood:adversarial`.

## Metric and resemblance authority

- Single-view IoU is forbidden. With at least two independently source-backed registered views it is only a correspondence aid, never an objective, ranking metric, or resemblance proof.
- Correspondence, resemblance, spatial coherence, and physical readiness are independent obligations.
- Identity-bearing geometry requires construction-vocabulary authority; resemblance evidence binds source-bound perceptual signatures and the neutral-clay barrier.

## Public discovery

- A fresh worker completes the canonical chain from an installed skill copy without reading raw implementation (`npm run dogfood:fresh-worker`).
- Copied installed-skill authority is closed over public exports and schemas (`npm run check:discovery-closure`).
