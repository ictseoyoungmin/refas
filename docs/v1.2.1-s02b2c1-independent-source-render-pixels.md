## Failure

Even after S02b2b ensured that the registered hero PNG was rendered from the current authoritative GLB with the previously selected camera, the worker's `registered-comparison/v1` can contain invented `metrics.perceptual.pixelShape` and foreground counts, using internally consistent digest/re-signed report bytes. A worker can claim shape agreement in the report even when the raw original source photo shows a displaced negative-space opening.

## S02b2c1 read-only independent evaluator

- New installed Python `source_render_pixel_screen.py`, reusing the production `compare_registered.py` original source warp, foreground, area, edge and pixel-shape screen without reading worker-authored report/metrics. It consumes only the **actual original image bytes**, registered GLB hero PNG bytes, registration and ROI.
- New public `evaluateIndependentSourceRenderPixels` resolves project-contained current source/PNG/registration bytes, enforces size budgets and exact caller-authoritative SHA-256, validates/replays registration semantics using `validateReferenceRegistration` (source SHA, hero SHA, required source/hero citations), freezes these verified bytes to private temporary files and executes independent Python pixels. Returns `USABLE` or `INSUFFICIENT`, and `cannotAuthorizeReferenceFidelity: true`, never a visual PASS.
- The registered homography remains **placement authority, not source shape truth**. Unknown/ambiguous registration is `INSUFFICIENT`; source and render segmentation unreliable (nonuniform corners/clutter or tiny subject) is `INSUFFICIENT`, not agreement.
- Actual encoded PNG tests: identical masks produce zero discrepancy but no resemblance certificate; same foreground area and same outer bounding box with an original's left interior negative-space slot vs render's right slot expose substantial two-sided mismatch **without trusting authored report**; noisy/corner-cluttered reference is explicitly insufficient; SHA tamper and path traversal fail.

## Remaining trust boundary — explicitly not S02b2c complete

**S02b2c1 is a usable standalone verifier but is not yet mandatory at Host, checkpoint, source-bound certification or audit.** At S02b2c2, the caller must obtain the original primary source manifest/bytes from the immutable project state, the hero from S02b2b actual GLB independent replay (not just from an author-provided PNG) and a digest-bound canonical registration artifact valid in project lineage. It must re-derive *all* relevant `perceptual.pixelShape` metrics and reject mismatches between independent evidence and re-signed worker metric claims, including a reproducible equal-area/void-shift negative. Where actual primary-source segmentation is insufficient, automatic source-fidelity cannot be claimed; preserve uncertainty/REVIEW_REQUIRED, not a fabricated pass. This will require replacing old deliberately uniformly colored 'real source' test fixtures with meaningful source photos or separately scoping contract tests, **not bypassing production checks**.
