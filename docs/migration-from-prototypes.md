# Migration from pre-1.0 prototypes

Pre-1.0 snapshots mixed temporary work state with product architecture. RefAs 1.0 imports evidence and validated behavior, not historical stage identity.

## Keep, translate, or discard

| Prototype material | 1.0 treatment |
|---|---|
| Raw references and visual review boards | Keep as provenance-bound evidence; recompute source digests. |
| Accepted child GLBs | Keep as immutable bytes; inspect and compose without regeneration. |
| Observed cells, adjacencies, landmarks, and correspondences | Translate into semantic surface-network, hierarchy, observation, or registration artifacts. |
| Actual albedo, object-ID, normal, side, oblique, and grazing renders | Keep when the asset and camera are traceable; otherwise rerender. |
| Temporary stage labels in filenames or schemas | Discard; history belongs in checkpoint lineage. |
| Hard-coded current-work prose in agent instructions | Discard; executable project state and `resume` own continuity. |
| Pointer-only rollback records | Replace with content-addressed artifact objects and exact byte restoration. |
| Aggregate pass/fail scores without localized findings | Retain only as metrics; create an evidence-cited typed finding before repair. |
| Duplicate child reconstruction inside parent builders | Replace with closed-child composition and registration data. |
| Per-cell duplicate frames | Replace with one physical boundary per observed shared adjacency. |

## Import procedure

1. Create a new project and bind each primary reference by SHA-256.
2. Re-express the visual hierarchy with semantic IDs and normalized contextual ROIs.
3. Separate directly visible facts from interpretations, hypotheses, and unresolved ambiguity.
4. Convert accepted camera/depth alternatives and correspondence sets into current spatial and registration artifacts.
5. Inspect legacy GLBs. Preserve accepted child bytes; rebuild only invalid or untraceable assets.
6. Translate observed cells and pairwise adjacency into a surface network. Do not import procedural regularization as observation truth.
7. Create an assembly contract and validate it against actual parent renders.
8. Commit fresh capability checkpoints with current artifact digests and evidence-backed gates.
9. Run a typed rollback exercise, full audit, and whole-object certification.

There is no compatibility alias for old stage identifiers. Silent aliasing would reintroduce the architecture defect that 1.0 removes.
