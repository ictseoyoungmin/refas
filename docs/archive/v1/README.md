# RefAs 1.x documentation archive

These documents preserve the architecture, contracts, plans and release history
of RefAs 1.x. Start from the [current documentation](../../README.md) for 2.0
development or the [retained 1.x guide](../../legacy-1x.md) for an older project.
The former production roadmap and renderer plans here are historical proposals,
not the current development queue.

| Historical subject | Entry points |
|---|---|
| Architecture and scope | [1.1 architecture](architecture.md), [known limitations](known-limitations.md) |
| Construction and physical contracts | [Physical semantics plan](physical-semantics-plan.md), [integrated fixture](integrated-physical-fixture.md), [parameter fitting](parameter-fitting.md) |
| Product and renderer planning | [1.0 development plan](development-plan.md), [post-1.2.1 production roadmap](development/foundry-production-roadmap.md), [1.4 renderer work plan](development/v1.4.0-render-work-plan.md) |
| Release history | [Release contracts](release-criteria.md), [1.4 release evidence](development/v1.4.0-release-readiness.md), [1.4.1 release evidence](development/v1.4.1-release-readiness.md) |

The original relative organization is retained, including the `development/`
subdirectory and versioned reports. Literal paths, commands, version statements
and measured results describe the recorded checkout. In particular, historical
`skills/refas/` paths do not identify the current production implementation;
the retained code now lives under `legacy/v1/` at the repository root.

Existing 2.0 evaluation and recovery records remain at
[`docs/development/evidence/`](../../development/evidence/). Moving these 1.x
documents does not rewrite those source records or confer current asset approval.
