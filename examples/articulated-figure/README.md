# Articulated figure dogfood

This fresh reconstruction uses an independent photograph of a crouching wooden drawing mannequin. The source image is intentionally excluded from the repository because redistribution permission is not assumed.

```bash
npm run dogfood:articulated -- --source /absolute/path/to/reference.png
```

The run creates a source manifest, visual hierarchy, source-space landmarks, two spatial hypotheses, section-profile geometry, a parented local-pivot assembly, reference and neutral GLBs, portable and independent PBR multiview renders, a realized-GLB projection, a registered comparison, an identity-bearing construction record, and a certification audit under `output/`. The checked-in failure-mode source is intentionally not allowed to certify: a successful command may report `certified: false` with `REFUSED_BLOCKING_SOURCE_RENDER_DISAGREEMENT` while retaining every board and digest as recovery evidence.

Closure priority is visual: a new check is added only when it binds evidence already needed for the reconstructed form. Geometry corrections are reviewed in source → hero → oblique/side/grazing order, and metrics rank or localize candidates but never choose the visual verdict. The generated comparison intentionally reports a blocking source/render disagreement until the pose is source-grounded; its raw IoU/foreground occupancy is only a screening aid because the pale, gradient source background is not a reliable foreground mask. The registered split/overlay and the typed projection finding own the decision.

The PBR board uses a source-like light background and a fixed, digest-bound three-light/exposure calibration so wood appearance is judged against the same visual context as the reference. A `certified: false` result is therefore an honest retained recovery checkpoint, not a claim that the pose is finished.

Open `viewer.html` after a successful run to switch between the source pose and the materially different neutral pose while orbiting the exact generated GLBs.
