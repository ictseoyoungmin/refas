## Literal instructions and implementation snapshot

Each actual author instruction, later lead feedback and independent review
request is saved before dispatch in [prompts](prompts/). The dispatch records
identify the recipient, context mode, saved text hash and timestamps. The
current user request and attachment identities are included. A terminal newline
is added to text files; otherwise the message text is literal.

The initial authors use a frozen copy of the 277-file skill at the base commit. Its exact
file identities are in [skill-snapshot.json](skill-snapshot.json). Runtime
repairs and guidance derived during this work are validated separately; they
are not retrospectively credited as the instructions that produced a model.
Exact backend model identifiers, tokens and costs are not available.

After the first blind review tied the jacket candidates, an explicitly informed
second correction joined the collar and lapels. That correction uses the actual
extracted current npm package, whose identity is in [checks/package.json](checks/package.json),
and receives a separate fresh-context blind review. The first candidate and its
literal tied review remain unchanged. Compatibility replays of the earlier
selections are separate from the initial frozen-skill authoring executions.

## Work and observation

- Import each selected native into a separate new production project through
  the public CLI; preserve the original bytes and full failed/intermediate runs.
- Compare actual before/after renders at fixed cameras, framing, lights,
  Blender 4.3.2, Cycles CPU, 512 square pixels, 16 samples, AgX and no denoising.
  Use the same settings for each matching detail pair. These cameras are
  unregistered to the original concept sheets.
- Inspect the whole source, whole asset, responsible region and surface depth.
  Use real geometry, material and silhouette observations; a successful command
  or unchanged object count does not decide reference quality.
- Keep jacket cuffs and ornaments, arm joint/digit hierarchy and service-cover
  semantics. Name every intentional change and compare protected state.
- Exercise the jacket cuff from 6 to 7 cm and the arm cover by 3 mm. Restore all
  selected artifacts and captured inputs byte-for-byte. Reopen native and GLB;
  inspect actual export images and sampled arm poses.

## Independent visual judgment

A fresh reviewer receives only the complete unchanged original sheets and
anonymous A/B matching render pairs in an isolated context. Identity, chronology,
code, author reports, intended fixes and the mapping are excluded. The mapping
is kept outside its packet until the literal review is returned.

Ask separately for relative preference and finished visual acceptance. Record
specific defects and uncertainty even if the refinement is preferred. A pose
sample is not continuous collision clearance; a GLB is not an engine test.
UVs, skin deformation, cloth simulation and physical mechanism feasibility
remain outside this continuation unless separately demonstrated.
