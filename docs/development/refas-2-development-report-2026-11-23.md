## 1. 마무리 판단과 공개 상태

**네이티브 제작·수정·복원·관찰·패키징의 알파 구현은 실제 실행 검증을 갖췄다. 오토메일은 선언한 사용 범위에서 채택됐으며, 재킷은 전체 캐릭터 착용 실패로 미승인이다.** 사용자 요청에 따라 추가 모델·피팅·내보내기 실험을 멈추고 완료 결과와 실패 후보를 보존했다. 이후 사용자가 PR 갱신을 명시적으로 요청하여 소스·합성 대조·집계 변경의 반영을 준비한다. 새 모델·내보내기 검사는 실행하지 않았다.

활성 패키지·Python·플러그인은 `2.0.0-alpha.1`, 보존한 기존 런타임은 `1.4.2`, 기록상 공개 릴리스는 `v1.4.1`이다. **`12076a3e`는 PR 갱신 전 원격 기준**, **`03b4a5c`는 검증한 로컬 core**이며 선행 토폴로지 수정은 `026317b`다. 이전 자동 승인 검토가 공개 업로드를 거절했던 이력은 유지한다. 현재는 새 PR 갱신 요청에 따라 준비된 공개 범위의 변경을 PR #399에 반영할 단계다. 실제 반영 성공·새 원격 SHA·그 head의 CI 결과는 아직 확인하지 않았으며 추정하지 않는다. main 병합·태그·정식 배포는 별도 미완료 단계다.

공개 문서는 소스·합성 대조·집계만 포함한다. 개인 모델·정점·이미지·비공개 전달 링크는 제외한다. [현재 상태](../WORK_STATUS.md), [후속 집계](evidence/usable-assets/recovery/topology-continuation/summary.json).

## 4. 토폴로지·관찰 개선과 채택 오토메일

100개 의류 메시의 **실제 평가된 정지 자세 삼각형**을 고정하고, 꼬인 파이핑·등 봉제선 다섯 스트립을 수정했다. 고정 시점의 트림 **28개 × 97프레임 = 2,716 객체 프레임**은 자체 교차·퇴화·방향 반전·삼각형 변경·보호 좌표 변경 없이 통과했다.

작은 공면 교차를 `BVHTree.overlap`이 누락하는 반례 때문에 후보 수집을 float64 AABB로 바꾸고 기존 SAT 판정을 유지했다. 여섯 대조, 2,000개 스칼라 일치, 30개 brute-force 후보 누락 검사를 통과했다. 이전 BVH로 걸러낸 접촉 0 주장은 이 결과로 대체한다. 이후 좌표를 바꾼 저작 수정에 “삼각형만 변경” 보존 주장을 자동 이전하지 않는다. [후속 보고](evidence/usable-assets/recovery/topology-continuation/README.md).

채택 오토메일 candidate 08은 **86,564삼각형·99메시/primitive·20제어 객체**다. 원본 321부품 중 289개는 상세 형상이 같고 32개 수리는 명시했다. 사전 예산 110,000삼각형·180 primitive·0.6 mm 아래이며, 수리한 상세본 대비 양방향 유한 표본 오차는 **0.423727 mm**다.

선언한 **133쌍 × 121프레임 = 16,093** 접촉 검사를 교정된 방법으로 재실행해 0을 확인했다. 실제 Godot의 119노드 × 121시점, 뒤집힌 실제 GLB 음성 대조, 국소 편집 시 114무관 객체 보존과 16파일 정확 복원이 통과했다. 손바닥·손목의 기능 리토폴로지와 단순 감면은 구별한다. **U4·U5 인정 범위는 선언한 rigid reach/partial-grip**이며 임의 자세·연속 시간·물리 파지·GPU 성능은 포함하지 않는다. 유한 표본 오차도 연속 표면 상한이 아니다. [자산 보고](evidence/usable-assets/automail-resume/README.md), [독립 검토](evidence/usable-assets/recovery/review-automail-candidate08.md).

## 5. 재킷의 미승인 후보와 최신 실패

재킷은 **100메시·122,898삼각형**으로 125,000 예산 안에 있다. 389개 체인 링크를 보존한 내부 하드웨어 및 국소 어깨·벨트의 부분 검증은 완료됐다. 이전 하드웨어11 검토본에서 원본 26메시와 금속70의 176,540쌍 프레임은 접촉 0이었다. 그러나 기존 착용 대상 3개 외에 원본 23개를 추가하자 바지·벨트와 불투명 머리카락의 실제 관통이 발견됐다. 부분 성공을 전체 착용으로 승격하지 않는다.

중단 요청 당시 실행 중이던 v5 affine 대안도 완료 결과를 보존했다. 3자세 일부 형상·착용 관찰은 통과했지만 BODY 상세/저감 표본 오차가 **1.669290 mm > 1.5 mm로 실패**했다. 전체 97프레임·칼라 오차·재질·하드웨어·export 최종 승인은 없다.

## 6. 다음 작업과 승인 조건

1. **하부 세 침투를 최소 범위로 수리한다.** v4 주된 피팅을 기준으로 세 부속의 원래 바깥 표면 부착을 회복한다. 천30의 435쌍, 얇은 면, 기존 BODY/COLLAR 11영역, 금지10관계·미등록 관계, 주변 금속과 원본26을 먼저 3자세에서 확인한다. 변경8지지는 원래 치수·재질·행 구성과 삼각형 대응으로 독립 유도하고 검토한다. 후보 접촉 극값에 맞춘 예외는 추가하지 않는다.
2. **상부 문제를 하부 수리와 병렬 준비하되 합본 전 필수로 닫는다.** 원본 보존 조건에서 hair/collar 수정 방향을 결정하고, 합의한 허용 범위의 상부 실제 후보를 만든다. 같은 카메라·재질 외형과 실제 알파 기준 불투명 교차, 인접 형상·동작을 다시 확인한다. 방향 결정만으로 완료 처리하지 않는다.
3. **통과한 수정만 실제 저작한다.** 49상태 목표·독립 잔차·클립·fps·원래 bake 보고 해시와 수정 내용을 남긴다. 같은 피팅을 상세 참조에 적용해 1.5 mm 표본 오차를 확인한다. 버클 frame/tongue의 공통 강체 연결을 유지해 합치고 변경 데이터를 명시한다.
4. **정확한 최종 파일에서 승인 증거를 완성한다.** 97프레임 전체 천·금속·원본26, 삼각형·가중치·모프·동작 보존, 원시 GLB와 Godot 재생, 좁은 간격의 실제 면 관찰을 같은 해시에 묶는다. 전체·세부·내부·와이어·자세 재질 뷰, 설치본의 의미 있는 편집·정확 복원과 독립 검토 후에만 U2/U3/U6를 갱신한다.
