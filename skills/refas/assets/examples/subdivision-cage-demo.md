# Runnable construction kernel example

From the installed RefAs skill root:

```bash
node scripts/subdivision-cage-demo.mjs
```

This executable uses the **actual** public `createLandmarkCage` and
`createSubdivisionCageOrganic` API with a closed, semantically labeled
demo cage. Its output reports geometry and watertightness only. It is
**not** an observed-source reconstruction, identity-bearing operation
permit, candidate checkpoint, resemblance certificate or strict release
handoff. Replace the illustrative coordinates with source-grounded
observations and follow `references/construction.md` to use the
permit-aware production path.
