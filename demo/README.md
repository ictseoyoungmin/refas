# RefAs 1.0.2 demo

`demo/index.html` is a dependency-free release showcase for the current RefAs 1.0.2 capability boundary.

It intentionally does not commit opaque generated GLBs or screenshots as proof. Instead it links the repository's reproducible examples and explains which authority chain makes a release claim trustworthy:

`source → relational structure → semantic authority → candidate relational closure → candidate → sealed evidence transaction → claim policy → claim decision → certificate`.

Open `index.html` directly in a browser. To produce actual geometry/render evidence, run the linked repository examples from the repository root.

## Scope

The demo describes only behavior already present in the 1.0.2 runtime. `UNKNOWN` is distinct from `FORBIDDEN`, and evidence- or requirement-supported hidden form may be classified as `INFERRED` or `ENGINEERED` without becoming source truth. RefAs still does not claim unseen manufacturer-internal truth without evidence, simulation-ready physical assemblies, calibrated mass/collider/actuator parameters, or fully resolved 3D orientation where the available reference remains ambiguous. See `docs/known-limitations.md`.
