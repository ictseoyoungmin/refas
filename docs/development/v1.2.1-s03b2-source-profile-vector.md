## Threat and admission

An agent can sign a valid shape-stage `realized-projection` where its chosen `anchorBindings[].localPoint` at the face center and expected nose-tip both agree with original source geometry, while the **actual** GLB nose mesh has been shifted to the wrong side. Valid GLB + camera + matching point anchors does not prove face-part correspondence.

Within the existing nonfixture Host `ensureEarlyResemblanceAdmission` (before committing `surface-topology` or downstream), after verifying SHA-bound original source, shape-stage CAS GLB, frozen selected camera, replayed derived mesh projections, source macro section and in-plane unsigned axis:

1. Use upstream `reference-geometry/v1` visible, primary-source-cited semantic roles **`face-center`** and **`nose-tip`**, each tied to exactly one non-detail, source-visible 2D part polygon by `anchorIds`.
2. Require independently projected `realized-projection/v1` segments for **separate actual current GLB mesh nodes**, not two agent-supplied local-point anchors on a single body mesh. Projected hull centroids determine the signed physical displacement.
3. When the original 2D source visibly presents lateral profile displacement (>=0.045 normalized image width and horizontally dominant), reject reversed, collapsed or angle-inconsistent physical nose displacement. Frontal, hidden, occluded, missing, duplicate or unclear evidence is **INSUFFICIENT**, never guessed.
4. **`NO_DETECTED_CONTRADICTION` is not `Reference Fidelity PASS`**. No conclusion about world-space face gaze, camera-independent yaw, actual anatomical interpretation, or independently established feature semantics follows from a single photo. Missing face observations are `NOT_APPLICABLE` but not a positive claim.
