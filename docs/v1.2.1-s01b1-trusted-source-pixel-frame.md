# S01b1 — Trusted primary source pixel-frame replay

Tracking parent: [#272](https://github.com/ictseoyoungmin/refas/issues/272). Base: `develop/v1.2.1@07f383100712cbdfed756ccb0ee117f1bee39b12`. Owner: existing `source-intake` verification, consumed read-only by the existing QA coverage evaluator. No new capability, certificate, generic image-generation step, or asset-specific threshold.

## Failure mode

A RefAs project can bind a JSON source manifest whose file SHA and declared width/height are internally consistent even when the source is no longer a decodable photograph. Source SHA proves **identity**, not the existence of original image pixels. The S01a source-manifest CLI guarded its own generation, but an alternate worker could hand-author a manifest and pass the original SHA-only verification.

## Implemented trust boundary

- The installed Node runtime exports `inspectSourcePixelFrameBytes(sourceBytes, manifest)` through the normal public library.
- The source-bound QA evaluator reads only a project-contained **current raw primary source** and passes exactly those bytes to the installed `source_pixel_frame.py` decoder through stdin; no candidate-controlled file path or caller-authored Python result is accepted.
- The Node owner independently verifies raw SHA-256/size before decoding; the decoder reuses the already tested S01a Pillow implementation to structurally verify the original still-image stream, reject unsupported EXIF transforms, completely load raster pixels, and report encoded width/height.
- The Node runtime independently checks parsed decoder output, coordinate-space identity and manifest dimensions. Missing Python/Pillow, timeout, invalid pixels, stale source, EXIF orientation drift, incomplete frame or forged dimensions remain FAIL, never silently PASS.
- Existing `verifySourceBoundObject(..., source-bound-object)` adds the mandatory `primary-source-pixel-frame` source-intake check. A valid GLB with a fake-but-SHA-valid original source becomes BLOCKED while a valid actual PNG/JPEG gets a **pixel-frame integrity PASS only**, never a Reference Fidelity certificate.

## Tests and known limits

Regressions cover real encoded PNG and JPEG positives, independently digest-valid non-image, wrong image dimensions with correct SHA, EXIF 6, changed raw source bytes, stale SHA and absent original source. Full package test, fresh worker, Node 20/22/24 and release audit are required before canonical closure.

**Still not proven:** This does not verify that an author-drawn `reference-geometry` contour or manual source mask actually corresponds to image pixels. A registered candidate render and original photograph have not yet been independently compared for face/shoulder/torso/negative-space differences. Existing checkpoint shape-to-detail admission remains distinct from the final QA evaluator; S01b2 must connect source-pixel-frame replay to **actual upstream checkpoint and Host accepted transitions** while preserving explicit contract-fixture tests. Until then this remains the **S01b1 sub-slice only**, not S01 overall, not #272 CLOSED, and no Reference Fidelity or Game Ready PASS.

No original/private reference photo or derived GLB should be committed into this public repository. The test images are small synthetic Pillow-generated rasters. Preserve stable `main` v1.2.0 unchanged.
