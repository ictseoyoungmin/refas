# v1.2.1 S01b2 — Trusted raw-image replay at shape-to-detail admission

Parent: [#272](https://github.com/ictseoyoungmin/refas/issues/272). Integration baseline: `develop/v1.2.1@3d4fd8aecf5716a04ee7ba28cc3281353a617d36`. Scope: existing `shape-reconstruction × whole` checkpoint/Host entry, no new capability or certification engine.

## Existing discrepancy

S01b1 checked real encoded raster pixels in read-only final QA but did **not** prevent a source-bound worker with a SHA-consistent, bogus image from accepting `surface-topology` and later detail checkpoints. The previous `ensureEarlyResemblanceAdmission` used only source manifest file size and SHA plus an author-declared `reference-geometry` proof. Those do not prove that a primary photo raster actually exists.

## Enforcement

The installed `checkpoint-store.mjs` now reuses public `inspectSourcePixelFrameBytes` directly inside `ensureEarlyResemblanceAdmission`, exactly at the source-bound transition to `surface-topology` or any later capability. There is no new policy-based bypass or second gate:
- Skip explicitly trusted internal contract fixture projects only, using the **existing** `isTrustedContractFixtureProject` authority check. A public project cannot become a fixture merely by inserting a fake manifest acquisition string; this slice does not change fixture authority semantics.
- Resolve original `state.source.path` from the project root, verify realpath containment, preflight original byte budget, read exact raw bytes, independently verify manifest SHA/size, replay Pillow structural and full image decoder on the same bytes, and compare encoded dimensions/orientation with `state.source`.
- Any undecodable original, swapped source, fake/digest-valid nonimage, unsupported EXIF transform, incorrect width/height or missing Python/Pillow raises `primary source pixel-frame REVIEW_REQUIRED` rather than allowing accepted detail.
- Existing `commitCheckpoint` uses `ensurePrerequisites → ensureEarlyResemblanceAdmission`; Host APIs that call this canonical commit path get the same veto. The established `auditProject`, `assessCertification` and `resumeProject` replay the same early resemblance admission for downstream states without trusting worker-provided PASS.
- Rejected commits do not change project head or accepted checkpoint IDs. `resumeProject` returns the existing `REQUEST_RESEMBLANCE_REVIEW` path. No generated certificate, saved image, model or source-copy mutations.

## Tests

The prior early-resemblance nonfixture fixture incorrectly bound arbitrary text bytes as `photo-reference`; the test now embeds a small **real decoded PNG** (synthetic raster, not a real photo likeness claim) so that unrelated spatial/camera/geometry positives and negatives remain meaningful.

Added raw-source adversarial tests use a SHA-consistent text-based fake primary image, and a real PNG whose manifest width is wrong despite matching SHA. These fail at real `surface-topology` checkpoint commit while a matching real source continues through the existing positive route. The refusal also keeps the head unchanged and returns review-required guidance. Existing trusted internal contract fixture behavior remains explicit.

## Not claimed

This is **source pixel-frame integrity**, not an independent observation extractor. An author may still draw a false 2D contour matching their GLB while citing the real photograph. S02 must compare the actual registered rendered GLB with **independently extracted** photo-space visual geometry, including occlusion and negative space. Never treat Image decode PASS, one-view IoU, a neutral-clay report, or a worker-declared source contour as an automatic Reference Fidelity PASS.
