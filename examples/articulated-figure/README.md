# Articulated figure dogfood

This fresh reconstruction uses an independent photograph of a crouching wooden drawing mannequin. The source image is intentionally excluded from the repository because redistribution permission is not assumed.

```bash
npm run dogfood:articulated -- --source /absolute/path/to/reference.png
```

The run creates a source manifest, visual hierarchy, source-space landmarks, two spatial hypotheses, section-profile geometry, a parented local-pivot assembly, reference and neutral GLBs, portable and independent PBR multiview renders, a realized-GLB projection, a registered comparison, an identity-bearing construction record, and a certification audit under `output/`.

Closure priority is visual: a new check is added only when it binds evidence already needed for the reconstructed form. Geometry corrections are reviewed in source → hero → oblique/side/grazing order, and metrics rank or localize candidates but never choose the visual verdict.

Open `viewer.html` after a successful run to switch between the source pose and the materially different neutral pose while orbiting the exact generated GLBs.
