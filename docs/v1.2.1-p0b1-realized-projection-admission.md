## Bounded defect and implemented replay

The installed `commitCheckpoint`/early resemblance admission already requires source-bound macro observations and a neutral-clay shape barrier, but could ignore a **shape-stage** `refas.realized-projection/v1` even when it was supplied and its measured macro mismatch contradicted the self-authored resemblance PASS.

This slice reuses the existing trusted runtime and current source-geometry and projection-verification modules:

- **If** a `realized-projection` is recorded in the shape checkpoint, require exactly one such artifact, canonical stored bytes/SHA, matching current source SHA and scope, actual current shape candidate GLB digest, and original primary source **and** candidate GLB path cited in the declared evidence.
- Read the candidate's current GLB bytes from inside project root with size and SHA checks. Independently call `verifyRealizedProjection({proof,referenceGeometry,glb})` to recompute the real projected coordinates, camera digest and geometry linkage.
- Reuse `findingsFromRealizedProjection` as the already published blocking threshold/typed finding authority; fail-closed on material macro anchor orientation/proportion, source-visible interface or occlusion mismatch. No worker-supplied `PASS` or normalized projected pixels can override.
- If there is **no shape-stage projection**, this first slice does not pretend camera acceptance is established; the mandatory missing-camera/projection source-to-shape coverage gate is still P0b2. The test positive is a real non-fixture source-bound checkpoint with a current GLB and valid camera. Negatives: moved model landmark with recomputed candidate source projection; changed camera with recomputed projection; claimed rendered XY tampering inside persisted canonical artifact.
