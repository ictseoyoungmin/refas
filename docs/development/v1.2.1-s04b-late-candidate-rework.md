Status: candidate for bounded P0 #272 S04b; not a full S04/1.2.1 release claim.

## Newly demonstrated failure

Previously accepted `shape-reconstruction` contains an original-source-cited GLB, camera and registered projection. A subsequent `surface-topology` / `assembly` candidate transition can legitimately update the authoritative GLB bytes, while the early admission gate still inspects only the older shape-stage GLB. The downstream GLB may be perfectly valid yet visibly violate frozen source macro proportions, even though all the early reference geometry and original camera evidence remain unchanged.

## Implementation

The public `reopenFromTrustedSourceAdmission` recovery entrypoint now, after validating the installed original shape-stage early gate, resolves **the actual authoritative final GLB candidate along the CURRENT selected checkpoint lineage**. If its SHA differs from the original shape GLB, it reads the **trusted content-addressed current GLB bytes**, creates a new realized projection from actual geometry using only *verified original shape-stage node-local bindings*, frozen source-selected camera and primary original source geometry, and evaluates source-bound macro anchor findings, segment envelopes/axis, signed face profile, actual part depth/occlusion and outer silhouette.

A physically wrong new candidate yields a typed `mass-proportion-mismatch` and follows the **existing** `reportFinding` rollback to `shape-reconstruction`, invalidating all dependent accepted detail/assembly/appearance/render/critique/certification. A candidate missing original node binding or invalid GLB requires `REVIEW_REQUIRED`, not a fabricated successful comparison or guessed 3D source meaning. An actually corrected GLB can be re-admitted after replaying the valid shape stage. Identical candidate SHA skips redundant latest replay.

No independent recognition of source semantics is claimed: source annotations and original camera still originate from prior source-bound observations. This is a late candidate *geometry mutation veto*, not new human review discovery, not a multi-view gaze claim and not positive Reference Fidelity certification.
