## Existing relationships worth preserving

The current digit chain positions already produce different finger lengths and a useful fan, so changing those origins would spend effort while increasing regression risk.

`SERVICE_COVER` currently owns the lid, vents, screws and status light. The existing edit script moves its entire descendant subtree by exactly **+3 mm local Y** and checks protected neighbors. New bay mechanisms must therefore remain outside that subtree; any new lid ribs or hinge hardware intended to move with the lid belong inside it.
