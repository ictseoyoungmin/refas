## Threat and fix

S02b2b authenticates the current exact GLB, source-selected frozen hero camera and actual generated PNG, but an agent could still supply a re-signed `registered-comparison/v1` containing invented source/render masks, area, edge and `pixelShape` values. Even a consistent hash or matching camera is not source-likeness evidence.

Within the existing nonfixture `commitCheckpoint(whole-object-certification)` prewrite admission and `inspectCertificationHead` (therefore certify, readiness, resume and audit), the caller now:

1. Replays the **current lineage-bound GLB** using the pre-shape, primary-source-cited selected camera through the trusted installed rasterizer, and checks exact hero PNG bytes and report.
2. Requires exactly one current checkpoint-bound `reference-registration` with canonical project-relative path and exact file SHA matching `registered-comparison.registration`. Its attested evidence must cite the original primary-source path and the reproduced hero. Missing/mismatching registration refuses admission; `compare_registered.py` now emits a project-relative registration path instead of an installation-dependent absolute path.
3. Calls installed `evaluateIndependentSourceRenderPixels` with the original project state's SHA-bound source image, the independently replayed exact hero SHA, the checkpoint-bound registration bytes and whole registered ROI, rather than reading worker metrics.
4. Derives the **whole-source registered ROI** independently by projecting the four full-image corners through the validated canonical homography; rejects a signed worker report that substitutes a small ROI to hide silhouette/negative-space mismatches. Does not use a worker-authored crop as observation authority.
5. Rejects contradictory or re-signed `sourceForegroundPixels`, `renderForegroundPixels`, perceptual edge/area/bounds/pixelShape fields. Nested comparisons use property-order-independent structural matching; numeric differences beyond bounded floating tolerance are rejected.
6. Treats unreliable/ambiguous foreground masks as `INSUFFICIENT/REVIEW_REQUIRED`, and strong opposing source-only/render-only occupancy as source-bound REWORK. An exact pixel comparison only means **no detected contradiction**, never positive Reference Fidelity authority.

For nonfixture source-bound certification, missing mandatory comparison evidence blocks **before committing a final checkpoint**. The installed contract-fixture system remains separate and cannot be entered merely by relabeling source metadata. This is no additional certificate authority, no new 12th capability, and no single-view IoU PASS.
