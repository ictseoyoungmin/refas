## Intended release boundary

Version 1.4.0 promotes the performance, reuse, and material-preview changes developed in `develop/v1.4.0`: shared visibility and cache, compiled/tiled CPU rendering, PBR-v2 supported material/texture paths, exact-input evidence, and optional external Blender Cycles diagnostics. Stable v1 renderer/camera evidence namespaces and published tags remain unchanged.

**Not part of this release:** source-photo-registered Hero/multiview likeness certification (R14-06F), generalized photometric CPU/Cycles equivalence or complete glTF PBR material coverage, calibrated real-world physical truth, or universal agent model-making success. Unsupported features keep explicit typed refusals or non-certifying previews. Monster Bed source and camera evidence remain private and are not committed or sent to a public CI runner.
