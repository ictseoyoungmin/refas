# RefAs v1.2.1 S03c1 — source-visible part depth occlusion screen

Parent P0 #272, feature-frozen release integration. **Bounded sub-slice**; no positive photo-likeness or unobserved torso depth inference.

## False-positive it fixes
An original source image visibly establishes one shoulder part in front of another. A worker may provide correct image-space 2D center and part envelopes while physically swapping the GLB parts along camera depth. S03a/S03b2 (outer envelope/face lateral profile) do not establish true depth order. Agent-authored projection-fit depth numbers are not trusted GLB measurements.

## Trusted runtime
- `deriveRealizedSegmentation` decodes actual GLB POSITION for each semantic segment binding, applies glTF hierarchy/node transforms and the frozen source-selected camera, and saves **actual vertex-based camera-depth extrema** on replayed `derivedSegments`. The canonical `realizedProjectionDigest` now binds depth extrema, and the standard verifier reconstructs it against exact current candidate GLB bytes.
- `screenSourceRealizedOcclusion` consumes only source-visible, primary-source-cited, typed front/back segment relationships, independent current actual segment mesh-node ownership, overlapping source part envelopes and overlapping realized convex hulls. If back is provably entirely nearer than front => REWORK. If all front vertices are provably nearer than all back vertices => **NO_DETECTED_CONTRADICTION** (not `Reference Fidelity PASS`). Intersecting/ambiguous depth ranges, non-visible evidence or single mesh as two parts => INSUFFICIENT. Projected parts that no longer overlap => REWORK.
- Nonfixture Host `ensureEarlyResemblanceAdmission` requires the result before accepted `surface-topology` and downstream. Existing source/shape GLB CAS identity, source camera, scope, replay and source-to-render checks still control admission.
- No invented per-pixel depth or physical hidden volume; depth ranges do not prove true **pixel-accurate** triangle visibility for interlocking parts. Such cases remain INSUFFICIENT. Actual GLB triangle raster and profile section may be added only with independent observed source evidence.

## Regression contract
- Genuine two-part GLB with shoulder boxes in positive near/far order admits this screen only; opposite GLB z-translations with equal 2D image-space source and macro envelopes return REWORK.
- Re-signing old projection fails exact swapped GLB byte replay.
- Interpenetrating z-ranges and shared node ownership return INSUFFICIENT.
- Missing primary source citation/partial or inferred source unsupported => INSUFFICIENT.
- Current Host path rejects forged two semantic occlusion parts on a single actual GLB mesh **without moving checkpoint head or advancing detail**.
